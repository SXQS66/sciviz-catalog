图2 · 模块-性状关系热图
每行 = 一个模块（MEblue、MEbrown…）· 每列 = 一个表型性状

📖 每个格子里的信息

  • 上方数字：相关系数 r（方向 + 强度）
  • 括号内：P 值（统计显著性）
  • 红色 = 正相关（模块↑ → 表型↑）
  • 蓝色 = 负相关（模块↑ → 表型↓）

🚫 最常见的误区

  • ❌ 只盯着最红的格子选模块
  • ❌ 把热图当成“颜色深浅图”来读
  • ❌ 看到颜色深就下结论，忽略 P 值
🔑 正确做法：相关系数 + P 值 + 研究背景 三者结合判断
不要只看最红的格子
要看“模块-性状组合”
WGCNA 的重点不是找一个最红的格子

① 看相关性强度

  • |r| ≥ 0.4 或 0.5 以上才值得关注
  • P 值要 显著（如 P < 0.05）
  • 颜色深但 P 值不显著 → 不靠谱

② 看与研究主题的匹配度

  • 代谢研究 → 关注 体重、血糖、胰岛素
  • 心血管研究 → 关注 钙化、动脉病变
  • 和主题无关的性状，颜色再深也不适合做主线

③ 看与多个表型的一致性

  • 某模块同时与 体重、脂肪、血糖 正相关
  • → 更像一个 “代谢状态模块”
  • 比单独一个格子 更有说服力
📌 选模块 = 找 和研究主线最贴近 的模块，而不是颜色最深的模块
一个模块能同时和多个相关表型连起来，后面的逻辑会更顺

🧩 从热图到关键模块 · 六步筛选法

📋 六步筛选流程

  • ① 看相关性：与核心性状的 r 和 P 值
  • ② 看一致性：是否与多个相关表型方向一致
  • ③ 看模块大小：太小不稳定，太大太混杂
  • ④ GO/KEGG 富集：模块基因指向什么功能？
  • ⑤ 筛选 hub gene：结合 MM 和 GS
  • ⑥ 外部验证：跨数据集或实验验证

🎯 模块筛选的优先级

  • 优先：与目标表型显著关联 + 基因数 ≥ 30
  • 次之：与多表型一致 + 功能富集有意义
  • 跳过：grey 模块（未分配基因）
  • 跳过：P 值不显著的小模块
⚡ 不是所有模块都要做 GO/KEGG · 聚焦核心即可
📌 模块划分 → 模块-性状相关 → 候选模块 → 功能富集 → hub gene → 验证
关键模块不是热图上直接“点名”的，而是一步步筛选出来的
💡 总结 · WGCNA 的进阶思考
从模块走到功能，再从功能走到 hub gene，这才是 WGCNA 能讲故事的地方

✅ 核心 Takeaways

  • 热图的颜色只是 提示，不是结论
  • 选模块要看 r + P + 研究背景
  • 关注模块与 一组相关表型 的一致性
  • 模块颜色是 标签，不是功能
  • WGCNA 的价值 = 把复杂表达矩阵 整理成可解释的模块

🧠 进阶思考

  • 软阈值：不只看 R²≥0.9，还要看曲线形态
  • 样本量：n<30 时结果不稳定，需谨慎
  • 模块保守性：跨数据集验证模块是否稳定
  • hub gene：MM 和 GS 双高才是核心
  • 相关 ≠ 因果：WGCNA 发现关联，验证靠实验
