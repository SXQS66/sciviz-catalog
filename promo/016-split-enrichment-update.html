上一期的补充：阈值怎么定，通路太胖时先砍哪一层。

富集上下调通路瘦身

方向性富集：上下调分离的三部曲

本文是 No.013 的更新版，把方向性富集拆成三步：① 上调、下调基因分别做 ORA，避免正负调控互相抵消；② 对每个方向按「基因数过滤 + FDR + 富集倍数 + 生物学审查」瘦身，保留 3–8 条核心通路；③ 输出带方向标签的结论。混合富集会让「活化 vs 抑制」无法区分，是差异分析最常见的失分点。

混合富集陷阱

  • 上/下调基因相互稀释，p值失真
  • 完全丢失功能方向性（活化 vs 抑制）
  • 真实机制被掩盖，误导下游验证

分离富集优势

  • 上调ORA → 揭示激活的炎症/信号转导
  • 下调ORA → 代谢抑制/凋亡抵抗/分化受阻
  • 直接匹配表型，高影响力期刊规范

核心原则：依据 log₂FC 方向分割上调/下调基因，分别进行超几何检验

混合富集 = 生物学信号的“中和反应”

方向性ORA · 标准流程

上调列表： log₂FC > 阈值 (如 >1)，adj.p < 0.05

下调列表：log₂FC < -阈值 (如 <1)，adj.p < 0.05

  • 背景基因集：同一参考基因组注释（Ensembl/Entrez）
  • 独立超几何检验 + Benjamini‑Hochberg (BH) 校正
  • 多重假设校正后 FDR (q‑value) < 0.05
  • 富集倍数 = GeneRatio / BackgroundRatio，用于排序筛选
  • 后续瘦身：基因数过滤 (10~200) + 生物学相关性审查

独立ORA → 分别输出上调/下调富集表，保留方向性

通路瘦身 · 精选核心机制

严格过滤标准

  • 基因数过滤：10～200 (排除过窄/过泛通路)
  • FDR (q‑value) < 0.05
  • 按富集倍数 (Fold Enrichment) 降序排列
  • 人工审查，剔除功能冗余通路

最终核心通路池

  • 上调方向保留 3～5 条 (激活/炎症/增殖)
  • 下调方向保留 3～4 条 (代谢抑制/凋亡抵抗)
  • 选取富集倍数最高且与表型密切相关的通路

方向性ORA是避免“信号抵消”的黄金标准

误区纠正 · 核心清单

常见误区

  • 合并上下调直接ORA → 丢失方向
  • 仅凭原始p值取top10 → 假阳性/无生物学支持
  • 忽视上下调协同网络 → 机制割裂

正确策略

  • 上调/下调独立ORA，综合解读
  • 基因数过滤 + FDR校正 + 富集倍数排序 + 人工审核
  • 绘制上下调通路网络图，分层阐释

核心通路池构建清单（精简版）

① FDR < 0.05 且基因数 ≥ 10；② 按富集倍数降序排列；③ 剔除冗余及与表型无关的通路；④ 每个方向保留3～8条最终通路。
