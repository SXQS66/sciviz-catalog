方向性富集（更新版）：通路瘦身策略

把差异基因按方向拆成两张表，再用四道闸门把上百条通路收敛到可读的 3–8 条。

富集上下调通路瘦身

为什么必须拆开上下调

方向性富集的做法很朴素：把差异基因按 log₂FC 的正负分成两张表，各自做一次 ORA（过表达分析），最后分别解读。理由同样朴素——一次 ORA 只能回答「这批基因在功能上偏向哪」，而把活化与抑制的基因混在一张表里，两股相反的信号会互相稀释：p 值被抬高、富集倍数被压平，最后只剩「免疫相关」这类谁都不得罪的结论。

做法能回答的问题典型丢失
混合 ORA（上下调合并）整体功能偏向活化 vs 抑制的方向、被相互抵销的代谢改变
方向性 ORA（上下调分开）哪一支被启动、哪一支被关闭无（代价是结果表翻倍，需要人工收敛）

所以方向性富集不是「更花哨的玩法」，而是把一次模糊的功能描述拆成两条可验证的假设：上调表指向被启动的程序，下调表指向被关闭的程序。

第一步：把基因分成两张表

分流本身不难，难在几个口径必须一次定死，否则上下调两张表的结果无法并列比较：

口径写法注意
上调log₂FC > 1 且 padj < 0.05阈值必须左右对称；log₂FC = 1 即 2 倍（见 No.014）
下调log₂FC < −1 且 padj < 0.05
背景基因集本次实验实际检出并参与检验的全部基因不是全基因组注释：低表达被过滤的基因不进背景，否则 p 值会系统性偏保守
检验与校正两张表各自做超几何检验 + BH 校正分开做，各自得到独立的 q 值列

排序指标统一用富集倍数 Fold Enrichment = GeneRatio / BgRatio：它不受通路大小影响，比单看 p 值更能挑出「小而锐」的信号。

# DESeq2 结果 → 按方向拆表（示意）
res <- results(dds, contrast = c("condition", "JA", "mock"))
res <- res[!is.na(res$padj), ]

up   <- rownames(res)[res$log2FoldChange >  1 & res$padj < 0.05]
down <- rownames(res)[res$log2FoldChange < -1 & res$padj < 0.05]
universe <- rownames(res)   # 背景 = 检验过的基因，不是全基因组注释

第二步：四道闸门做通路瘦身

一次 ORA 常吐出几十到上百条通路，直接读等于没读。下面的顺序不能随意调换：每一步只解决一个问题，前一道闸的结果才决定后一道闸看什么。

闸门做法拿掉什么
基因数过滤命中基因数落在 10–200只有两三个基因的「过窄」通路，与塞进数百个基因的「过泛」通路
FDR 门槛q < 0.05（BH 校正）校正后仍不显著的噪声
富集倍数排序按 GeneRatio / BgRatio 降序大而钝、靠基因数堆出来的通路
生物学审查人工判读与表型、处理条件是否自洽统计显著但与本课题无关的通路

下限为什么取 10：与 clusterProfiler 的默认 minGSSize = 10 对齐；上限 200 是人为收紧的可调值（其默认 maxGSSize = 500）。通路上限放得越宽，泛通路越容易挤进前排——这一步没有普适数字，只有与本课题匹配的尺度。

四道闸走完，每个方向通常剩十几条。最后按生物学主线收敛到 3–8 条：再多也读不过来，反而淹掉主要结论。

案例：茉莉酸处理番茄叶片，两种读法差在哪

同一批差异基因（|log₂FC| > 1 且 padj < 0.05，上调 547、下调 412），分别用混合 ORA 与方向性 ORA 跑一遍，得到的结论并不等价：

分析策略前排通路（命中基因数）能读出的方向
混合 ORA植物激素信号转导、MAPK signaling只知道「激素与信号转导被扰动」，激活还是抑制说不清
上调 ORA植物激素信号转导（38）、MAPK signaling（29）、次生代谢合成防御与激素通路被启动
下调 ORA光合作用-天线蛋白（21）、淀粉与蔗糖代谢（17）、卟啉代谢光合与能量代谢被关闭

模拟数据：上表数值用于演示两种读法的差异，非真实实验结果。可用的结论须四项同向：方向、通路、命中基因数、与表型自洽——本案例里防御通路升高与光合通路下降合起来，才构成植物典型的防御—生长权衡。

四个常见误区

误区后果改法
上下调合并做一次 ORA方向性信息被抵销按 log₂FC 正负拆成两张表
按原始 p 值取 Top10假阳性，且系统性偏向大通路用 BH 校正后的 q 值 + 富集倍数排序
背景集写成全基因组注释p 值系统性偏保守，真信号被压掉背景 = 本次检出并参与检验的基因
只报通路名，不报命中基因数读者无法判断这条通路是否「撑得住」表格里带上命中基因数与 GeneRatio

还有一步常被跳过：把上下调通路放进同一张网络图，看两支是否指向同一个调控枢纽。方向性富集的终点是可验证的机制假设，不是一张通路清单。

小结

  • 先分流——按 log₂FC 正负拆表，背景集锚定本次检出基因；
  • 再瘦身——基因数 10–200 → FDR → 富集倍数 → 生物学审查，四道闸缺一不可；
  • 后收敛——每个方向留 3–8 条主线通路，带方向标签与命中基因数输出；
  • 终落点——把两条方向的路谱并到一张网络图上，提出可验证的机制假设。
