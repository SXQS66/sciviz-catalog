互作实验五兄弟：IP / CoIP / ChIP / pull-down / BiFC

五种互作验证实验的适用边界，以及各自最常见的假阳性来源。

IPCoIPChIP互作

互作实验五兄弟：先问「找什么」，再定方法

导师说「做个互作实验」时，先别急着挑名字。IP、CoIP、Pull-down、RIP、ChIP名字都跟「沉淀」沾边，本质上只回答两类问题：蛋白和谁结合？蛋白和哪种核酸结合？按「你在找什么」分类，而不是按编号背名字：

研究对象可选方法验证语境
蛋白 – 蛋白IP / CoIP / Pull-down体内富集 / 体内验证 / 体外直接结合
蛋白 – RNARIP抗体抓 RBP，下游 RT-qPCR 或测序
蛋白 – DNAChIP交联锁定，下游 qPCR 或测序

蛋白 – 蛋白

  • IP：以蛋白为诱饵，富集目标蛋白
  • CoIP：捞 A，顺带带出搭档 B
  • Pull-down：体外验证是否直接结合

蛋白 – RNA

  • RIP：抗体抓 RBP，顺带拽下 RNA
  • 下游用 RT-qPCR 或测序鉴定

蛋白 – DNA

  • ChIP：交联锁住蛋白–DNA 复合物
  • 下游用 qPCR 或测序鉴定结合位点

最容易混淆的是 IP、CoIP、Pull-down 这三兄弟——都以蛋白为诱饵，但目的完全不同，本文重点拆解。而 RIP 与 ChIP 分别对应蛋白–RNA、蛋白–DNA 互作，区分起来相对简单。

IP（免疫沉淀）：把目标蛋白单独捞出来

IP 的关键词是富集——它本身不直接验证互作，但能为互作筛选铺路。

原理

  • 特异性抗体识别目标蛋白抗原
  • 「目标蛋白–抗体」复合物锚定在磁珠或琼脂糖凝胶微球固相载体上
  • 洗涤去除非特异性吸附的杂蛋白，洗脱得到目标蛋白

通俗地说

  • 抗体 = 只认一个用户 ID 的精准搜索引擎
  • 磁珠 = 承载这次提取的"服务器"
  • 把目标用户从平台里单独调出来，连同资料打包带走

研究目的

  • 从细胞裂解物中富集获取目标蛋白
  • 富集蛋白复合物，为后续实验（如质谱鉴定互作蛋白）做准备

关键特点

  • 只针对目标蛋白开展富集，本身不直接验证蛋白–蛋白互作
  • 若对沉淀得到的复合物做质谱，可筛选潜在互作蛋白

核心理念

  • 用蛋白 A 的抗体把 A 沉淀下来
  • 若 A 在细胞内天然与蛋白 B 结合成复合物，B 会"搭便车"一起被拉下
  • 再用 WB 检测 B，即证明 A–B 互作

适用场景

  • 验证两个已知蛋白在细胞内天然状态下是否存在相互作用
  • 这是体内验证蛋白互作的金标准

关键提醒

  • 基于细胞内天然复合物，结果贴近生理状态，真实性高
  • 无法区分直接互作与间接互作：A 和 C 结合、C 又和 B 结合，B 同样可能被拉下，造成"A–B 直接互作"的假象
  • 单纯 CoIP-WB 仅可验证已知蛋白的互作；搭配质谱 CoIP-MS，可发掘新的互作蛋白

Pull-down：在体外证明「是否直接互作」

思路是把诱饵固定在固相载体上，看猎物会不会自己贴上来。

  • 把已知蛋白（诱饵）固定在固相载体上
  • 与含潜在互作蛋白的样品孵育
  • 能直接结合的蛋白（猎物）被捕获，洗脱后鉴定身份
  • 验证两个蛋白是否「直接结合」，排除间接互作干扰
  • 从裂解液中筛选与诱饵蛋白结合的未知蛋白（配合质谱）
  • 体外环境与细胞内不同，需设合理对照排除非特异性结合
  • 常用 GST-tag、His-tag 等融合蛋白作诱饵，须确保标签不影响蛋白天然折叠与功能
  • Pull-down 得到的互作候选是体外条件获得，阳性结果还需细胞内实验（如 CoIP）进一步验证生理状态下的互作

注：本文中 Pull-down 特指以蛋白为诱饵的蛋白 Pull-down。此外还有 RNA pull-down、DNA pull-down，分别研究蛋白–RNA、蛋白–DNA 互作。

RIP（RNA 免疫沉淀）：蛋白找它的 RNA 搭档

抗体抓 RBP，顺带把结合的 RNA 一起拽下来。

  • 用 RNA 结合蛋白（RBP）的特异性抗体免疫沉淀该蛋白
  • 顺带拉下与之结合的 RNA
  • 再用 RT-qPCR 或测序鉴定 RNA 身份
  • 验证某个已知 RNA 是否与目标 RBP 结合
  • 通过 RIP-seq 高通量筛选 RBP 在细胞内结合的全部 RNA
  • 全程必须抑制 RNase 活性——RNA 一旦降解，实验就白做了
  • 须设置 IgG 对照和 Input 对照，确保信号特异性

ChIP（染色质免疫沉淀）：蛋白找它调控的 DNA

甲醛交联「冻结」复合物，再打断、沉淀、解交联。

  • 先用甲醛交联「冻结」细胞内蛋白–DNA 复合物
  • 将染色质打断成 200–500 bp 片段
  • 用目标蛋白抗体免疫沉淀
  • 解交联释放 DNA 后，用 qPCR 或测序鉴定
  • 验证转录因子或组蛋白是否结合特定 DNA 区域（如基因启动子）
  • ChIP-seq 全基因组筛选蛋白结合位点
  • 交联条件和片段大小是成败关键——交联过度则难以解交联，片段过大则分辨率下降
  • 必须设 Input 对照和 IgG 对照

快速决策指南：三步选对实验

Step 1 · 确定互作对象

  • 蛋白 vs 蛋白 → 进入 Step 2
  • 蛋白 vs RNA → RIP
  • 蛋白 vs DNA → ChIP

Step 2 · 确定验证目的

  • 证明两个已知蛋白在体内是否互作 → CoIP
  • 证明两个蛋白是否直接结合（体外） → Pull-down（GST / His pull-down）
  • 只需富集目标蛋白本身 / 为质谱筛选做准备 → IP

Step 3 · 是否需要高通量

  • 已知目标核酸序列 → qPCR 验证
  • 想全基因组 / 全转录组层面筛选 → ChIP-seq / RIP-seq

顺序别搞反：先定对象，再定目的，最后定通量。一句话口诀——IP 捞蛋白，CoIP 带出伙伴，Pull-down 验直接互作，RIP 抓蛋白拽 RNA，ChIP 交联锁 DNA。

下次导师再让你「做个互作实验」，先问自己两个问题：我要找谁和谁的互作？在体内还是体外验证？答案一出，实验自然就定了。
