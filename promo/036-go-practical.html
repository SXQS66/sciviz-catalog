GO 富集实战手册：从跑通到读懂

R 与 Python 两套完整代码、五个高频误区，以及把条目列表写成生物学故事的三步改写法。

GO富集clusterProfilergseapy解读

五分钟回顾：GO 是什么

GO（Gene Ontology）4从三个维度系统注释基因功能：BP（生物过程，如细胞凋亡、免疫应答）、CC（细胞组分，如线粒体、核糖体）、MF（分子功能，如 ATP 酶活性、DNA 结合）。一句话：GO 告诉我们基因「在哪儿、做什么、怎么工作」。本文从一份差异分析结果出发，把 GO 富集完整跑通，再解决「结果一堆却句句空话」的解读难题。

标准分析流程（0 基础友好版）

  • 读取差异分析结果：从 DE_results.csv 开始；
  • 筛选差异基因：|log₂FC| ≥ 1 且 FDR < 0.05；
  • 基因 ID 转换：转成 ENTREZID / ENSEMBL（不要直接用 Symbol）；
  • 设定背景基因：必须用「本次测序检测到的所有基因」；
  • GO 富集分析：超几何检验 + BH 校正；
  • 结果解读与报告：围绕科学问题聚焦关键条目。

R 语言实战（clusterProfiler）

示例输入 DE_results.csv 含 gene、log2FoldChange、pvalue、padj 四列；以小鼠（org.Mm.eg.db）为例，人类换 org.Hs.eg.db。富集与 ID 转换由 clusterProfiler1,2 完成。

# 首次安装：BiocManager::install(c("clusterProfiler","org.Mm.eg.db","enrichplot"))
library(clusterProfiler)
library(org.Mm.eg.db)
library(dplyr)

# 1) 读取并筛选差异基因
de  <- read.csv("DE_results.csv")
deg <- de |> filter(abs(log2FoldChange) >= 1, padj < 0.05) |> pull(gene)

# 2) ID 转换：差异基因 + 背景基因都要转
id_map <- bitr(deg, fromType = "SYMBOL", toType = "ENTREZID", OrgDb = org.Mm.eg.db)
bg_map <- bitr(unique(de$gene), fromType = "SYMBOL", toType = "ENTREZID", OrgDb = org.Mm.eg.db)

# 3) GO 富集（BP 示例；universe 必须是本次检测到的背景）
ego_bp <- enrichGO(gene          = id_map$ENTREZID,
                   universe      = bg_map$ENTREZID,
                   OrgDb         = org.Mm.eg.db,
                   keyType       = "ENTREZID",
                   ont           = "BP",
                   pAdjustMethod = "BH",
                   pvalueCutoff  = 0.05,
                   qvalueCutoff  = 0.05,
                   readable      = TRUE)

# 4) 可视化
barplot(ego_bp,  showCategory = 20, title = "GO-BP Enrichment (Top20)")
dotplot(ego_bp,  showCategory = 20, title = "GO-BP Dotplot (Top20)")

# 5) 导出结果
write.csv(as.data.frame(ego_bp), "GO_BP_enrichment.csv", row.names = FALSE)

Python 实战（gseapy）

Python 侧的 gseapy 封装 Enrichr3 服务，流程与 R 版一一对应：

# pip install gseapy pandas matplotlib numpy
import pandas as pd
import numpy  as np
import gseapy as gp
import matplotlib.pyplot as plt

# 1) 读取并筛选差异基因；背景 = 本次检测到的全部基因
df  = pd.read_csv("DE_results.csv")
deg = df.query("abs(log2FoldChange) >= 1 and padj < 0.05")["gene"].dropna().tolist()
bg  = df["gene"].dropna().unique().tolist()

# 2) GO 富集（小鼠；人类改 organism="Human"）
enr = gp.enrichr(gene_list   = deg,
                 gene_sets   = ["GO_Biological_Process_2023",
                                "GO_Cellular_Component_2023",
                                "GO_Molecular_Function_2023"],
                 background  = bg,
                 organism    = "Mouse",
                 outdir      = "gseapy_out",
                 cutoff      = 0.05)

# 3) 提取 BP 前 20 条并绘图
bp    = enr.results.query("Gene_set=='GO_Biological_Process_2023'") \
                   .sort_values("Adjusted P-value").head(20)
terms = bp["Term"].str.replace(r"\(\d+\)$", "", regex=True)

plt.figure(figsize=(8, 6))
plt.barh(range(len(terms)), -np.log10(bp["Adjusted P-value"]))
plt.yticks(range(len(terms)), terms)
plt.xlabel("-log10(FDR)")
plt.title("GO-BP Enrichment (Top20)")
plt.tight_layout()
plt.savefig("GO_BP_bar.png", dpi=300)

避坑指南：五个高频误区

误区正确做法
❌ 直接用 Gene Symbol 富集✅ 先转 ENTREZID / ENSEMBL，避免匹配错误与符号歧义
❌ 背景基因设为全基因组✅ 用本次实验检测到的基因集作背景，否则 p 值系统性偏小
❌ 仅凭 p-value 判断✅ 看 FDR（q-value）< 0.05，多重校正后更稳健
❌ 只做 BP，忽略 CC / MF✅ 三个维度结合，功能注释更完整
❌ 罗列全部显著条目✅ 优先选与研究最相关的 3–5 条并引文献支持

重点指标：GeneRatio 是差异基因中落在该条目的比例（分子/差异基因总数）；BgRatio 是背景基因中属于该条目的比例；pvalue / p.adjust 为超几何检验显著性及 BH 校正后 FDR，通常以 q < 0.05 为显著线。

解读策略一：删泛词 + 合并模块

富集结果一堆显著条目，写进论文却句句空话——不是数据不行，是解读停留在「翻译条目」阶段。第一步先剔除 GO 顶层宽泛条目：biological process、cellular process、response to stimulus、regulation of signaling 这类大词没有信息量，只能当背景，不适合当重点结果。第二步把相似条目合并成功能模块：

合并示例：「白细胞迁移 + 中性粒细胞活化 + 细胞因子信号 + 炎症应答」→ 一句话：炎症反应和免疫细胞募集增强。合并后写出来的是一句话，不是一个列表。

解读策略二：结合研究问题 + 关注核心基因

同一条目，不同课题写法不同：肿瘤转移研究往侵袭、微环境重塑上收；免疫疾病往免疫激活、炎症放大上收。不要只问「这个条目什么意思」，要问「它能不能解释我的疾病现象」。

同时记住：条目显著 ≠ 它就是核心机制，价值取决于富集背后的驱动基因。判断依据是条目里有没有 IL1B、TNF、CCL2、CXCL8 这类关键基因——如果贡献基因很散，或后续不打算讲，就不适合当主线。条目是外壳，核心基因是灵魂。

解读策略三：上下调分开 + 搭配 KEGG / GSEA

上调与下调基因的生物学方向不同：混在一起富集，往往只剩「免疫和代谢调控」式的泛条目；分开解读则双向逻辑清晰——例如上调集中在免疫激活、炎症应答、细胞迁移，下调集中在氧化磷酸化、脂质代谢、稳态调控，结论就能写成「疾病伴随免疫激活与代谢受损的双重改变」。

搭配使用：GO 给宽泛方向，KEGG 给具体通路（GO 提示免疫异常 → KEGG 落地为 TNF、IL-17、NF-κB），GSEA 从全局验证功能趋势。GO 负责「做什么」，KEGG 负责「怎么实现」（可视化见 No.034）。

解读策略四：讨论部分的正确写法

句式对照：错误——「本研究证明该基因通过炎症通路发挥作用」；正确——「富集结果提示这些差异基因可能与炎症反应相关，为后续机制验证提供了方向」。GO 仅基于注释做功能富集，只能提示相关性和趋势，不能证明因果关系。

GO 的价值不在于列出多少个显著条目，而在于帮你讲清楚这批差异基因整体在改变什么功能、指向什么机制。下次打开 GO 表格，先问自己：我是在翻译条目，还是在讲一个生物学故事？
