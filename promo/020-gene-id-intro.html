🧬 SYMBOL · 基因名
最直观，最常用，但也最容易出问题

✅ 优点

  • 直观易读 · 适合结果展示
  • 高频示例 · TP53, EGFR, VEGFA, GAPDH
  • 画热图、火山图、箱线图 首选

⚠️ 陷阱

  • 基因会 改名（旧名 vs 新名）
  • 存在 别名 和同义词
  • 多个不同 ID 可能转成 同一个 SYMBOL
  • 非编码 RNA 注释版本 不一致

📌 典型例子

TP53 EGFR VEGFA GAPDH ACTB
⚠️ 同一个 SYMBOL 出现多行 → 必须处理重复

🎯 使用场景

  • 结果展示 · 文章、图表
  • 机器学习 · 特征命名
  • 多队列验证 · 需注意旧名和缺失
🔑 SYMBOL 适合 展示，但分析时要注意 重复 和 改名
📦 ENSEMBL · 数据库编号
RNA-seq 数据中最常见的稳定 ID，注意物种前缀

📌 来源与例子

  • 来源 · Ensembl 数据库
  • 人类前缀 · ENSG00000141510 (TP53)
  • 小鼠前缀 · ENSMUSG00000059552 (Trp53)
  • 特点 · 稳定、唯一、适合定量
🌱 植物/其他物种前缀不同，需查阅 对应数据库

🎯 使用场景

  • RNA-seq · 原始定量结果（如 featureCounts）
  • TCGA / GEO · 多组学数据
  • GTF 注释 · 基因结构文件

📋 标准处理流程

  • RNA-seq 原始矩阵 → ENSEMBL
  • 展示时转 SYMBOL
  • 富集时转 ENTREZID
💡 关键注意 ENSEMBL 转 SYMBOL 并非 100% 成功，转换后务必统计丢失比例，并检查是否存在多对一（多个 ENSEMBL 对应同一个 SYMBOL）的情况。
ENSEMBL → 根据物种选择正确的注释包 → SYMBOL / ENTREZID
ENTREZID · 数字 ID
NCBI 的全局数字编号，富集分析的“通用钥匙”

📌 来源与例子

  • 来源：NCBI Entrez Gene 数据库
  • 人类示例：7157(TP53)，1956(EGFR)
  • 特点：纯数字，跨物种唯一，但不直观

🎯 核心用途

  • GO 富集：基因本体论分析
  • KEGG 富集：信号通路分析
  • GSEA：基因集富集分析

⚠️ 常见错误

  • 输入 SYMBOL 但富集函数参数指定为 ENTREZID
  • 输入 ENSEMBL 但未设置正确的 keyType
  • 人类基因错误使用 小鼠 注释数据库，非模式物种硬套人类数据库

📋 操作前检查清单

  • 我的输入基因当前是什么 ID 类型？
  • 这个函数/包要求输入什么 ID 类型？
  • 我加载的物种注释包 对不对，如 org.Hs.eg.db？
⚡ 这三个问题没弄清，富集结果为空或错误是常有的事
🔑 ENTREZID 是富集分析的 通用钥匙，但必须配合 正确的物种注释包
Probe · 芯片探针
本身不是基因，是芯片上用来检测表达的探针编号

📌 来源与例子

  • 常见于 · GEO 等数据库中的芯片数据
  • 例子 · 204016_at (Affymetrix)
  • 本质 · 探针是检测工具，不等同于基因本身

⚠️ 关键问题

  • 一个基因可能对应 多个探针
  • 不同探针的信号值可能 不一致
  • 必须通过 注释文件 将探针映射到基因

📊 重复探针合并方式

  • 取 平均值（最常用）
  • 取 最大值 或 中位数
  • 取 方差最大 的代表探针
  • 取 注释最可靠 的探针
💡 标准做法 先获取芯片平台对应的 GPL 注释文件，将 Probe ID 映射为 SYMBOL 或 ENTREZID，然后按需合并重复基因。
🔑 Probe → 平台注释 → SYMBOL / ENTREZID → 合并重复 → 后续分析
ID 转换 · 共性问题与检查
为什么转换后基因变少？代码没报错就是对的吗？

📉 基因数量减少的常见原因

  • 部分 ID 无法匹配 · 数据库版本或注释来源不同
  • 多个源 ID 映射到 同一个 SYMBOL（重复）
  • Probe 没有对应的 基因注释
  • 旧基因名未更新，或物种数据库 用错

✅ 转换后必须检查的指标

  • 原始 ID 总数 = N
  • 成功匹配的 ID 数 = M
  • 未匹配的 ID 数 = N - M
  • 去重后的唯一基因数 = U
📊 记录这四个数字，排查问题时一目了然
🚨 重要提醒 代码能够运行结束，并不代表 ID 转换是正确的。富集分析返回空结果或极少数基因，通常不是生物学上真的没有富集，而是 ID 类型或物种不匹配。
🔑 转换前明确三要素：当前ID类型 · 目标ID类型 · 物种

🧬 SYMBOL 展示用，需处理重复
📦 ENSEMBL RNA-seq 稳定 ID，去版本号
🔢 ENTREZID 富集分析通用钥匙
🔬 Probe 芯片探针，先注释再合并

✅ 核心原则

  • 确保分析矩阵中 每一行 代表一个唯一基因
  • 不同分析步骤可以灵活使用 不同的 ID 类型
  • 每次 ID 转换后 必须检查 匹配率与重复情况
  • 跨队列整合时，ID 统一 是首要前提

🧠 常见场景的处理逻辑

  • 芯片数据：Probe → 平台注释 → SYMBOL → 合并
  • RNA-seq 数据：ENSEMBL（去版本）→ 转换
  • 富集分析首选：ENTREZID + 对应物种的 org 包
  • 非模式物种：构建 自定义 TERM2GENE
🔬 可靠的转录组分析 = 高质量数据 + 正确工具 + 清晰的ID
💡 动手分析前，先问自己：表达矩阵的第一列，到底是什么 ID？
