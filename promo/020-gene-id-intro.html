基因 ID，你真的分清了吗

Ensembl / Entrez / Symbol / RefSeq 互转时的坑：版本号、别名、大小写。

基因IDEnsemblEntrezID转换

TP53、ENSG00000141510、204016_at——是同一个基因吗？

是。打开表达矩阵，第一列那些奇奇怪怪的 ID 常让人犯嘀咕：为什么有的像名字，有的像编号？它们来自不同命名体系——官方基因符号1、Ensembl ID2、Entrez 数字 ID、芯片探针——对应不同数据库与适用场景。下面这些翻车现场，多半不是方法选错了，而是第一步的基因 ID 没弄清楚：

  • 差异分析能跑，一到富集分析就报错？
  • ENSEMBL 转 SYMBOL 后，基因数突然少了一大截？
  • 同一个基因在矩阵里出现好几行，该信哪个？
  • 跨队列验证时，关键基因怎么也找不到？

四种核心 ID 一览

类型来源TP53 示例特点最佳用途
SYMBOLHGNC 官方基因名TP53直观易读，但有别名与改名问题结果展示：热图、火山图、图表标注
ENSEMBLEnsembl 数据库ENSG00000141510稳定、唯一，带物种前缀RNA-seq 定量矩阵的主键
ENTREZIDNCBI Entrez Gene7157纯数字、跨物种唯一，但不直观GO / KEGG / GSEA 富集分析
Probe芯片平台（Affymetrix 等）204016_at检测工具编号，不等于基因本身GEO 芯片数据，需先注释再合并

补充身份体系：RefSeq 参考序列（NM_001126112）锚定转录本；HGNC 与 MGI 分别是人类和小鼠命名的官方权威。核心原则一句话：让分析矩阵的每一行代表一个唯一基因。

SYMBOL：给人看的名字

TP53、EGFR、VEGFA、GAPDH、ACTB——画热图、火山图、写文章都靠它。但直观是有代价的：

  • 基因会改名（旧名 vs 新名），跨队列验证时旧文献里的名字可能已经失效；
  • 存在别名和同义词，同一个基因可能被写成几种样子；
  • 多个不同 ID 可能转成同一个 SYMBOL——矩阵里出现重复行；
  • 非编码 RNA 的注释在各版本间不一致。

结论：SYMBOL 适合「展示」，不适合当分析的主键。展示前务必处理重复行，跨队列整合时先统一命名版本。

ENSEMBL：给机器用的稳定主键

RNA-seq 原始定量结果（featureCounts / Salmon）、TCGA / GEO 的多组学矩阵、GTF 注释文件——这些「机器友好」的数据源几乎都以 ENSEMBL 为主键。ID 前缀自带物种信息：

物种基因 ID 前缀示例（TP53 / Trp53）
人类ENSGENSG00000141510
小鼠ENSMUSGENSMUSG00000059552

标准处理流程：RNA-seq 原始矩阵以 ENSEMBL 做所有分析 → 展示时转 SYMBOL → 富集时转 ENTREZID。注意两点：新版 Ensembl ID 带版本号后缀（.15 这类），转换前先去掉；植物等其他物种前缀不同，需查阅对应数据库。

关键提醒：ENSEMBL → SYMBOL 并非 100% 成功。转换后务必统计丢失比例，并检查多对一（多个 ENSEMBL 映射到同一个 SYMBOL）的情况。

ENTREZID：富集分析的通用钥匙

NCBI 的全局数字编号（人类 TP53 = 7157，EGFR = 1956）。GO、KEGG、GSEA 等 富集工具3都认它，但它必须配合正确物种的注释包使用。高频错误一览：

常见错误后果纠正
输入 SYMBOL 但函数参数写 keyType = "ENTREZID"全匹配失败，富集结果为空先 bitr() 转换，再按实际类型设 keyType
输入 ENSEMBL 未设置 keyType按默认类型匹配，命中寥寥显式声明 keyType = "ENSEMBL"
人类基因用了小鼠注释包（org.Mm.eg.db）匹配错乱，结果看似正常实则全错物种与 org 包一一核对（人 = org.Hs.eg.db）

操作前三问：① 我的输入基因是什么 ID 类型？② 目标函数要求什么类型？③ 我加载的物种注释包对不对？三个问题没弄清，富集结果为空或错误是常有的事。

Probe：芯片数据的「探针」不是基因

GEO 上的芯片数据用探针编号（如 Affymetrix 的 204016_at）。探针是检测工具，不等同于基因：一个基因可能对应多个探针，不同探针的信号值还可能不一致。标准做法是先获取芯片平台对应的 GPL 注释文件，把 Probe ID 映射为 SYMBOL / ENTREZID，再按需合并重复基因：

合并策略做法适用
取平均同一基因多探针表达值取均值最常用、最稳妥的默认选择
取最大 / 中位数取最高或居中的探针值关注最大表达信号时使用
取方差最大保留变异最大的代表探针差异分析，保留区分度
取注释最可靠按注释质量挑选代表探针注释质量参差的旧平台
 
Probe → GPL 平台注释 → SYMBOL / ENTREZID → 合并重复 → 后续分析

转换后必查的四个数字

N     = 输入 ID 总数
M     = 成功匹配数          匹配率 = M / N
N − M = 未匹配 ID（版本差异 / 无注释 / 物种用错）
U     = 去重后唯一基因数     重复度 = M − U

基因数量减少的常见原因：部分 ID 无法匹配（数据库版本或注释来源不同）、多个源 ID 映射到同一个 SYMBOL、探针没有对应基因注释、旧基因名未更新或物种数据库用错。记录这四个数字，排查问题时一目了然。

重要提醒：代码能够运行结束，并不代表 ID 转换是正确的。富集分析返回空结果或只剩极少数基因，通常不是生物学上真的没有富集，而是 ID 类型或物种不匹配。

常见场景的处理逻辑

数据场景推荐链路
芯片数据（GEO）Probe → 平台注释（GPL）→ SYMBOL → 合并重复
RNA-seq 数据ENSEMBL（去版本号）→ 展示转 SYMBOL / 富集转 ENTREZID
富集分析ENTREZID + 对应物种的 org 包
非模式物种无现成 org 包 → 构建自定义 TERM2GENE 映射表

核心原则：① 每次转换后检查匹配率与重复情况；② 不同分析步骤可灵活使用不同 ID；③ 跨队列整合时，ID 统一是首要前提。可靠的转录组分析 = 高质量数据 + 正确工具 + 清晰的 ID。

动手分析前，先问自己：表达矩阵的第一列，到底是什么 ID？
