🔬 WGCNA · 共表达网络分析
Weighted Gene Co‑expression Network Analysis
“哪些基因在样本中一起变化，并且和表型相关”

🎯 核心视角

  • 关注 基因模块 而非单个基因
  • 基于 基因间相关性 构建网络
  • 将零散基因 组织成协同变化 的群组

📊 输入 → 输出

  • 输入：表达矩阵 + 表型信息
  • 输出：共表达模块、模块‑表型相关、hub genes
🔗 差异分析看“单基因变化” · WGCNA 看“基因群协同变化”
从单基因到网络模块 · 解码疾病机制的结构化视角
⚖️ 差异分析 vs WGCNA · 互补视角

📈 差异分析

  • 核心问题：哪些基因在两组间显著变化？
  • 分析对象：单个基因
  • 主要依据：组间均值差异
  • 输出结果：上调 / 下调差异基因
  • ✅ 适合回答：哪些基因变了？

🌐 WGCNA

  • 核心问题：哪些基因呈现相似表达模式？
  • 分析对象：基因模块（共表达群组）
  • 主要依据：基因之间的相关性
  • 输出结果：共表达模块、模块‑表型相关、hub genes
  • ✅ 适合回答：哪些基因群和表型关系最密切？
🔹 两者是 互补关系，不是替代关系。
差异分析提供“候选点”
WGCNA提供“网络结构”和“表型关联”
单基因差异 + 共表达模块 = 更完整的机制线索
⚙️ WGCNA 三步流程 · 从基因到模块

第一步 · 计算相似性

  • 计算基因间 表达相关性
  • 构建 加权共表达网络
  • 选择软阈值 (power) 强化强相关
↓

第二步 · 聚类形成模块

  • 基于 拓扑重叠 进行聚类
  • 识别 共表达模块（如蓝色、棕色模块）
  • 每个模块代表一群 协同变化 的基因
↓

第三步 · 关联表型

  • 计算模块特征向量 (eigengene)
  • 模块与 临床表型 相关分析
  • 筛选 关键模块 与 hub genes
📌 基因表达相似性 → 共表达模块 → 表型关联 → 核心候选基因
三步构建从“基因网络”到“表型机制”的桥梁
🎯 为什么做 WGCNA · 三个核心价值

① 整理零散基因

  • 差异分析常得到 几百到几千 个基因
  • 难以判断哪些基因 协同变化
  • WGCNA 将零散基因 整理成模块，让结果更有结构

② 连接临床表型

  • 不仅比较两组，还可关联 年龄、分期、生存
  • 模块与 免疫评分、代谢评分 等连续变量相关
  • 形成比“某基因上调” 更完整的机制解释

③ 筛选 hub genes

  • hub gene = 模块内 连接度最高 的核心基因
  • 代表整个模块的 表达趋势
  • 常用策略：DEG ∩ 关键模块 ∩ hub genes
  • ✅ 候选基因证据 更强、更可信
差异分析 找“变化的点” · WGCNA 找“协同变化的网络”
WGCNA 让候选基因从“单点信号”升级为“网络共识”
📌 总结 · WGCNA 核心要点

✅ 核心价值

  • 从 单基因 到 共表达模块，提供结构化视角
  • 连接 基因网络 与 临床表型，增强机制解释力
  • 筛选 hub genes，提升候选基因可信度
  • 与差异分析 互补验证，形成更完整的证据链

⚠️ 常见误区澄清

  • ❌ WGCNA 和差异分析是重复的
    → 两者互补，不是替代
  • ❌ hub gene 一定是核心机制基因
    → 需结合差异分析、富集、验证等
  • ❌ 模块与表型相关 = 因果关系
    → 相关 ≠ 因果，需实验验证
  • ❌ 样本少也能做 WGCNA
    → 样本量不足时结果不稳定
  • ❌ 模块颜色有生物学意义
    → 颜色只是标签，基因内容才是关键
