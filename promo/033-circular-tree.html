原图与复刻思路

Science《Chinese Immune Multi-omics Atlas》的 Fig. 1E（Yin et al. 2026）用一整圈环形树画下了 72 种免疫细胞：谱系关系、细胞占比、Sex / Age 双组学信号全部收进一张图。本文拆解它的构图方法，并给出 R（tidygraph + ggraph）与 Python（matplotlib）双版本复现代码和同一份 input.csv 数据模板——双语言同款成图。

结构解剖（从圆心向外逐层堆叠，8 大构件）：根 → 主枝 → 胶囊枝 → 叶端 → 轨道 → 标签 → 图例 → 迷你树。

构图巧思：为什么这张图「多而不乱」

  1. 树形类比——细胞分类 = 从圆心生长的树，L1 谱系 → L2/L3 分支 → 叶端即细胞亚型；
  2. 扇区着色——5 大谱系淡彩扇底 + L3 同色环带与胶囊枝，层级一眼可辨；
  3. 四联轨道——内 Sex 外 Age 各两圈，ATAC 淡色 + 星号、RNA 饱和色；蓝 = Female/Younger，红 = Male/Elder；
  4. 编号衔接——叶端 1–72 编号方块衔接内外圈「细胞名 (占比)」标签；
  5. 图例系统——白底图例环抱轨道、右下迷你树复述结构、L1–L4 标尺辅助读图。

实现要点

  • 树布局：tidygraph 建树 + 极坐标 x = r·sinθ, y = r·cosθ；
  • 树枝：geom_edge_diagonal 弯枝，L3 用 geom_segment 直线胶囊；
  • 扇形与环轨：ggforce::geom_arc_bar 画扇区 / 环带 / 方块 / 轨道；
  • 发散配色：RdBu colorRamp + gamma 提亮中低强度；
  • 结构图例：cowplot 叠加右下角迷你树，matplotlib 同款复刻。

五步构图法（拿走即用）

  1. 整理宽表：一行一个细胞，层级 l1/l2/l3 + 占比 + 配色；
  2. 极坐标布局：θ = (i − 0.5)·2π/n，层级定半径；
  3. 画树枝：贝塞尔弯枝 + L3 径向胶囊枝（白字）+ 淡彩环带；
  4. 环形轨道：Wedge / geom_arc_bar 画 4 圈，ATAC 淡化、RNA 饱和；
  5. 图例系统：径向旋转 90° − θ 标签；白底图例盖轨道；cowplot 叠迷你树。

# =============================================================================
# Title: Circular cell annotation tree | 环形细胞注释树（Science Fig.1E 风格）
# Author: Shang Xia Qiu Suo
#
# 图面结构（由内向外）：
# 中心根节点 → L1 谱系主枝 → L2 分支 → L3 直线胶囊枝（白字标在枝内）
# → 72 个编号叶端方块 → 4 条环形轨道（内 2 圈 Sex / 外 2 圈 Age）
# → 外圈"细胞名 (占比)"两行标签
# 顶部白底 Age/Sex 图例 · 左下 L1-L4 层级标尺 · 右下角迷你树结构图例
#
# ★ 风格速调索引（最常改的参数都在这里，改完重跑脚本即可）：
# 全局字号   font_size      所有文字均写为 font_size / n，一改全改
# 谱系配色   lineage_colors L1 枝色 = 扇形底色基色，换风格先改这
# 发散色系   rdbu_pal       轨道热图色带（蓝↔红发散）
# 树的疏密   node_radius    各层半径；l3 越大 L3 越贴近叶端
# 枝干粗细   edge_widths    单位 mm；L3 胶囊粗细另见主图 linewidth
# 叶端方块   tip_r0 / tip_r1 两者之差 = 方块厚度
# 轨道圈数   tracks         加一行 = 多一圈；inner 为内半径
# 轨道厚薄   ring_w         色块缝隙见 pad
# L3 突出环带               段深浅看 mix_white(0.84)，外缘 r = 0.868
# 外圈标签   label_radius
# 顶部图例   annotate("label") y 需跟随 tracks 改动同步
# 迷你树     draw_plot(x,y,width,height) 画布相对坐标 0-1
# 画布范围   coord_fixed(xlim, ylim) 标签被裁时放大
#
# 运行环境（实测版本；更老版本可能出现 API 差异）：
# R 4.2.1 · tidyverse 2.0.0 · tidygraph 1.2.3
# ggraph 2.1.0 · ggforce 0.4.1 · cowplot 1.1.1
library(tidyverse)
library(tidygraph)
library(ggraph)
library(ggforce)
library(cowplot)  # 右下角迷你树图例叠加（ggdraw + draw_plot）

# 修复希腊字母渲染：强制 UTF-8 locale（默认 C locale 会把 γδ 变成点）
if (!l10n_info()$"UTF-8") {
  ok <- tryCatch(Sys.setlocale("LC_CTYPE", "en_US.UTF-8"), warning = function(w) NULL)
  if (is.null(ok)) Sys.setlocale("LC_CTYPE", "UTF-8")
}

font_size <- 14  # ★ 全局字号基准：所有文字 = font_size / n，n 越大字越小

# 1. 读取宽表并清洗 -----------------------------------------------------------
# input.csv 每行一个细胞亚型，必需列：
#   id        顺时针排序编号（决定叶端角度位置，务必从 1 连续编号）
#   l1/l2/l3  三级分类路径（l3 允许与 l2 同名）
#   cell_type 末级细胞名（外圈标签第一行）
#   percent   scRNA 占比（外圈标签第二行 / L3 胶囊枝内占比）
#   tip_color 该细胞的主题色（叶端方块 + L2/L3 枝 + 外标签）
#   sex_score / age_score 轨道热图数值，范围 [-1, 1]
#   sex_atac_stars 等四列显著性星号（空 = 不显示）
data <- read.csv("input.csv", stringsAsFactors = FALSE, na.strings = c("", "NA")) |>
  mutate(across(where(is.character), trimws)) |>
  arrange(id) |>  # id 决定顺时针顺序，先排序
  mutate(
    id = as.integer(id),
    theta = (row_number() - 0.5) * 2 * pi / n()  # 均匀铺满 360°，顺时针自顶部
  )
half_step <- pi / nrow(data)  # 每个叶端扇形单元的角度半宽（弧度）= π/n

# 2. 配色 ---------------------------------------------------------------------
# ★ 谱系主色：同时决定 L1 枝条颜色与内圈扇形底色（外标签色来自 tip_color 列）
# 换风格改这里的 hex 即可；新增谱系时追加一行
lineage_colors <- c(
  "CD4 T"   = "#2F4B8F",
  "CD8 T"   = "#23809D",
  "ILC"     = "#8A3B96",
  "B cells" = "#E08A00",
  "Myeloid" = "#7E9C3F"
)

# RdBu 发散色 ramp：score ∈ [-1, 1]，负=蓝（Female/Younger），正=红（Male/Elder）
# 想换色系：替换 11 个 hex，保持"深→浅→白→浅→深"左右对称即可套用任意发散色
rdbu_pal <- colorRamp(c(
  "#053061", "#2166AC", "#4393C3", "#92C5DE", "#D1E5F0", "#F2F2F2",
  "#FDDBC7", "#F4A582", "#D6604D", "#B2182B", "#67001F"
))
rdbu <- function(x) {
  x <- pmin(pmax(x, -1), 1)
  x <- sign(x) * abs(x)^0.55  # gamma 压缩：指数 <1 会提亮中小值；改成 1 = 线性映射
  rgb(rdbu_pal((x + 1) / 2), maxColorValue = 255)
}

# 向白色混合：f = 混白比例，f 越大越淡
# 本图用到三档：0.92 内圈扇形底（极淡）/ 0.84 L3 突出环带 / 0.74 ATAC 轨道淡化
mix_white <- function(col, f = 0.74) {
  m <- col2rgb(col)  # 0-255 标度
  rgb(m[1, ] * (1 - f) + 255 * f, m[2, ] * (1 - f) + 255 * f,
      m[3, ] * (1 - f) + 255 * f, maxColorValue = 255)
}

# 3. 整理作图数据 --------------------------------------------------------------
# 把每行宽表展开为 root→l1→l2→l3→cell_type 五个节点；
# name 用累积路径拼接，避免不同父分支下的同名节点被错误合并
paths <- data |>
  select(id, l1, l2, l3, cell_type, percent, tip_color, theta) |>
  mutate(root = "Cells", group = l1) |>
  pivot_longer(c(root, l1, l2, l3, cell_type), names_to = "level", values_to = "label") |>
  mutate(name = accumulate(label, paste, sep = " / "), .by = id) |>
  mutate(name = if_else(level == "cell_type", paste(name, id, sep = " / "), name)) |>
  mutate(from = lag(name), repeat_label = label == lead(label), .by = id)

# 节点表：theta 取其下属叶端的角度均值
# ★ node_radius 只表示层级深度（非进化距离）：l1/l2 越大中心越空；
#   l3 越大 L3 越贴近叶端（连接枝越短）；改后需同步主图 L1-L4 标尺的 y 值
node_radius <- c("root" = 0, "l1" = 0.19, "l2" = 0.42, "l3" = 0.86, "cell_type" = 1)
nodes <- paths |>
  summarise(label = first(label), level = first(level), theta = mean(theta), .by = name) |>
  mutate(radius = node_radius[level], x = radius * sin(theta), y = radius * cos(theta))

# 连线表：from 父节点 → to 子节点；proportion = 下属叶端 percent 求和
# ★ edge_widths 单位 mm（ggplot linewidth 尺度）：l1 主干最粗、cell_type 连接枝最细
# 注意：主图 L3 胶囊的粗细由 geom_segment(linewidth = 5.1) 单独控制，
#       此处 l3 的值仅作用于迷你树缩略图
edge_widths <- c("l1" = 7, "l2" = 3.2, "l3" = 5.1, "cell_type" = 0.8)
edges <- paths |>
  filter(level != "root") |>
  summarise(
    label = first(label), level = first(level), group = first(group),
    tip = first(tip_color), proportion = sum(percent),
    repeat_label = all(repeat_label), .by = c(from, name)
  ) |>
  rename(to = name) |>
  mutate(
    color = if_else(level == "l1", lineage_colors[group], tip),  # L1 用谱系主色，其余用叶端色
    branch_label = case_when(
      level == "cell_type" ~ "",                                   # 叶端连接枝不标字
      level == "l2" & repeat_label ~ "",                           # l2 与 l3 全员同名时抑制重复
      level == "l3" ~ sprintf("%s %.2f%%", label, proportion),     # 胶囊枝：名称 + 占比
      TRUE ~ label
    ),
    width = edge_widths[level],
    label_size = case_when(  # ★ 枝上白字大小 = font_size / n，n 越大字越小
      level == "l1" ~ font_size / 3.1,
      level == "l2" ~ font_size / 4.6,
      level == "l3" ~ font_size / 5.0,
      TRUE ~ 0
    ),
    label_pos = if_else(level == "l3", 0.55, 0.62)  # 文字在枝上的位置（0 父端 → 1 子端）
  )

# L3 胶囊 = 径向直线段（圆角矩形），与贝塞尔弯枝分开画：
# 主图树只保留非 L3 边（edges_main），L3 另用 geom_segment 画，便于控制粗细与文字
# ★ 想改回弯曲 L3 枝：删除 edges_main 过滤 + 主图两个 L3 图层，
#   让 geom_edge_diagonal 直接用完整 edges 即可
edges_main <- edges |> filter(level != "l3")
tree <- tbl_graph(nodes = nodes, edges = edges_main, directed = TRUE)
tree_layout <- create_layout(tree, layout = "manual", x = x, y = y)
tree_layout$circular <- TRUE   # manual 布局必须显式声明圆形
attr(tree_layout, "circular") <- TRUE
# 迷你树图例使用完整边（细枝缩略树，不剔除 L3）
tree_layout_full <- create_layout(tbl_graph(nodes = nodes, edges = edges, directed = TRUE),
                                  layout = "manual", x = x, y = y)

# L3 胶囊：L2 节点 → L3 节点的直线段
# xt/yt = 白字锚点（t = 0.55，与 edges 的 label_pos 对应）
# angle 归一化到 (-90, 90]，保证左半圆文字不倒置
l3_capsule <- edges |>
  filter(level == "l3") |>
  left_join(nodes |> select(name, x0 = x, y0 = y), by = c("from" = "name")) |>
  left_join(nodes |> select(name, x1 = x, y1 = y), by = c("to" = "name")) |>
  mutate(
    xt = x0 + 0.55 * (x1 - x0), yt = y0 + 0.55 * (y1 - y0),
    angle = atan2(y1 - y0, x1 - x0) * 180 / pi,
    angle = if_else(angle > 90, angle - 180, if_else(angle < -90, angle + 180, angle))
  )

# 4. 叶端、扇形底色与热图轨道 ---------------------------------------------------
# ★ tip_r1 - tip_r0 = 叶端方块厚度（0.05），想加厚调 tip_r1
# ★ ring_w = 轨道厚度；pad = 色块角向缝隙（弧度），调大缝隙更明显
tip_r0 <- 0.965; tip_r1 <- 1.015; ring_w <- 0.070; pad <- 0.002
tips <- data |>
  mutate(
    x = sin(theta), y = cos(theta),
    start = theta - half_step + pad, end = theta + half_step - pad,
    angle = 90 - theta * 180 / pi,           # 外标签径向旋转
    hjust = if_else(x < 0, 1, 0),
    angle = if_else(x < 0, angle + 180, angle)  # 左半圆翻转 180° 保证可读
  )

# 扇形底色两层：
#   内圈（0.02-0.42，L1/L2 区）= 很淡的谱系色（mix 0.92）
#   外圈 = L3 突出环带（见下），按 L3 分支着色
sectors_inner <- tips |>
  summarise(start = min(start) - 0.01, end = max(end) + 0.01,
            color = mix_white(lineage_colors[l1], 0.92), .by = l1) |>
  mutate(r0 = 0.02, r = 0.42)

# ★ L3 突出环带：包住每个 L3 分支的淡彩宽环（0.42 → 0.868）
# mix_white 0.84 = 深浅（越大越淡）；±0.006 = 角向外扩（相邻环带近乎相接）
# 外缘 0.868 与叶端内缘 0.965 之间留 ~0.1 作 L3 → 编号方块的连接枝空间
l3_ring <- paths |>
  summarise(start = min(theta) - half_step - 0.006,
            end = max(theta) + half_step + 0.006, .by = name) |>
  left_join(edges |> filter(level == "l3") |> select(to, color), by = c("name" = "to")) |>
  mutate(color = mix_white(color, 0.84), r0 = 0.42, r = 0.868)
sectors <- bind_rows(sectors_inner, l3_ring)

# ★ 4 条环形轨道：inner 为内半径，outer = inner + ring_w
# 加轨道：tribble 加一行 + ring_data 里加一段 transmute（列名前缀对应即可）
# 改组间距：调各 inner；改厚薄：调 ring_w
tracks <- tribble(
  ~track,     ~inner,
  "sex_atac", 1.035,
  "sex_rna",  1.117,
  "age_atac", 1.199,
  "age_rna",  1.281
) |> mutate(outer = inner + ring_w)

# 轨道数据：每个叶端一格；ATAC 圈 mix_white(f=0.74) 淡化 + 星号，RNA 圈饱和
ring_data <- bind_rows(
  data |> transmute(id, theta, stars = sex_atac_stars, score = sex_score, mod = "atac", track = "sex_atac"),
  data |> transmute(id, theta, stars = sex_rna_stars,  score = sex_score, mod = "rna",  track = "sex_rna"),
  data |> transmute(id, theta, stars = age_atac_stars, score = age_score, mod = "atac", track = "age_atac"),
  data |> transmute(id, theta, stars = age_rna_stars,  score = age_score, mod = "rna",  track = "age_rna")
) |>
  inner_join(tracks, by = "track") |>
  mutate(
    fill = if_else(mod == "atac", mix_white(rdbu(score)), rdbu(score)),
    radius = (inner + outer) / 2,
    x = radius * sin(theta), y = radius * cos(theta),
    angle = -theta * 180 / pi  # 星号沿轨道切向
  )
# 星号颜色：深色格用白星、浅色格用黑星（RGB 平均亮度阈值 130/255）
brightness <- colMeans(col2rgb(ring_data$fill))
ring_data$text_color <- if_else(brightness < 130, "white", "#202020")

# 顶部图例区不避让轨道：与参考实现一致，轨道完整绘制，
# 由两个白底 label 直接盖在轨道上方，文字被热图环抱
label_radius <- 1.46  # ★ 外圈标签的径向位置（越大脑外标签离圆越远）
outer_circle <- 1.42  # 绿色参考圆半径

# 5. 绘制主图 ------------------------------------------------------------------
# 图层自下而上：扇形底色 → 树枝 → L3 胶囊 → 叶端方块/编号 → 轨道 → 参考圆
# → 星号 → 外圈标签 → 顶部图例 → L1-L4 标尺
p <- ggraph(tree_layout) +
  # 谱系扇形底色 + L3 突出环带
  geom_arc_bar(
    data = sectors,
    aes(x0 = 0, y0 = 0, r0 = r0, r = r, start = start, end = end, fill = color),

def hex2rgb(h):
    return np.array([int(h[i:i+2], 16) for i in (1, 3, 5)], float)

def rgb2hex(c):
    return "#{:02X}{:02X}{:02X}".format(*(int(round(v)) for v in np.clip(c, 0, 255)))

def mix_white(h, f=0.74):  # ★ 向白色混合：f = 混白比例，越大越淡

    return rgb2hex(hex2rgb(h) * (1 - f) + 255 * f)

def rdbu(x):  # RdBu 发散色：负=蓝（Female/Younger），正=红（Male/Elder）
    x = np.clip(x, -1, 1)
    x = np.sign(x) * np.abs(x) ** 0.55  # ★ gamma 压缩：<1 提亮中小值；改 1 = 线性
    t = (x + 1) / 2 * (len(RDBU) - 1)
    lo = int(np.floor(t)); hi = min(lo + 1, len(RDBU) - 1); f = t - lo
    return rgb2hex(RDBU_RGB[lo] * (1 - f) + RDBU_RGB[hi] * f)
