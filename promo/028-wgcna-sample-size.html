WGCNA 样本量
最容易犯的错误：样本量不够还硬做
代码能跑出结果 ≠ 结果可信
小样本下的"完美"模块大多是统计假象
📌 样本越少，模块越"漂亮" —— 但越不可信
📊 十几个样本 → ⚙️ 硬跑WGCNA →
📈 r=0.9 热图 → ❌ 参数一变就消失
🔑 WGCNA 官方建议：至少 15 个样本，最好 20 个以上
⚠️ 样本 < 15：不推荐 📊 15–20：勉强可行 ✅ ≥ 20：推荐起步

🧬 WGCNA 分析的不是单个基因
而是基因与基因之间的 共表达关联

📊 差异分析

  • 对比两组样本的表达均值差异
  • 对样本量容错率相对较高
  • 每个基因独立检验

🔗 WGCNA

  • 捕捉基因间的共表达相关性
  • 需要足够样本清关联结构才稳定
  • 样本太少时，相关性极易被个别样本拉高
样本不足 → 相关估计噪声过大 → 模块无生物学意义
⚠️ WGCNA 官方 FAQ 明确指出：少于 15 个样本的数据集，相关性估计噪声过大，网络难以具有生物学意义
📈 小样本 = 相关性虚高
样本越少，模块与表型的相关系数反而越夸张

🧪 现象

  • n = 12 时，模块与表型 r = 0.85
  • 删掉 1 个离群样本 → r 跌到 0.4
  • 换一种缺失值处理方法 → 最相关模块变了
  • 漂亮的热图 ≠ 稳定的信号

🔍 原因

  • 相关系数在 小样本下极不稳定
  • 单个高表达样本就能拉高整个相关系数
  • 有限样本量下比较网络结构 → 易产生虚假发现
  • 高相关 ≠ 信号强，往往是统计假象
⚠️ 小样本的高相关，不代表结果好 —— 大概率是 不稳定的统计假象
🎯 Hub Gene 对样本量极其敏感
模块不稳定 → Hub Gene 自然也不稳定

🔄 同一个数据，不同设置

  • 第一次分析 → Hub Gene A
  • 换个软阈值 → Hub Gene B
  • 删除一个异常样本 → 关键模块被拆开
  • 重新选高变基因 → Hub 名单全换

💡 为什么

  • Hub Gene = 模块内连接强度最高的基因
  • 模块本身不稳定 → Hub 必然漂移
⚠️ 小样本下跑出的 Top Hub Gene，换个参数就可能完全消失 —— 这不是偶然，是样本量不足的必然
🚫 别拿差异基因跑 WGCNA
先筛 DEG 再跑 WGCNA = 自欺欺人，解决不了样本不足

❌ 问题

  • 先筛差异基因 → 人为预设了组间差异
  • 后续模块与疾病高度相关 → 前期筛选带来的人为偏差
  • 不是网络分析真实挖掘出的规律

✅ 正确做法

  • WGCNA 应使用低表达过滤后的大部分基因
  • 或一定数量的高变基因
  • 从全局共表达网络中无偏挖掘模块
  • 提前塞入显著基因 → 分析意义已改变
💡 WGCNA 的核心价值是 无偏挖掘，不是给 DEG 做二次验证
🔬 稳定性测试：结果可信的试金石
参数微调、样本扰动后依然稳定，才是真正可信的结果

🧪 测试方法

  • 删除一个样本后重新分析 → 关键模块还在吗？
  • 更换合理范围内的软阈值 → 模块划分大幅变化？
  • 调整高变基因数量 → 候选模块/Hub 稳定？
  • 有独立队列 → 模块保留性分析

📋 判断标准

  • 稍微改参数结果就变 → 稳定性有限
  • 关键模块、功能方向、候选基因在不同设置下仍相近
  • → 结果才值得继续往下做
💡 WGCNA 不是跑一次出图就结束了。尤其是样本不多时，稳定性检查比多画几张网络图更重要
🧭 核心要点
代码能跑完 ≠ 结果可信 · 稳定才是硬道理
⚠️ 样本量门槛
官方建议 ≥ 15，最好 ≥ 20
📈 相关性虚高
小样本下 r=0.9 不一定是信号强，往往是 统计假象
🎯 Hub 不稳定
模块不稳 → Hub Gene 漂移 → 换个参数 Top 名单全变
🔬 稳定性验证
删样本、换阈值、调参数 —— 结果不变才可信
⚡ WGCNA 真正有价值的，是找到 能够重复出现的共表达结构，而不是给每个项目配一张彩色模块图
📊 样本不足 → 不硬做 🧪 稳定性测试 → 必须做 ✅ 结果稳定 → 才可信
