Rust 开源生产力三件套：VectorCraft · WordCraft · PhotoCraft

三款 Rust 重写的开源「Adobe 平替」实测：共同的架构底色、各自的真实边界，以及该不该现在换过去的选型建议。

Rust开源MCP工具评测

共同底色：三个项目的四条公约数

VectorCraft（对标 Illustrator）、WordCraft（对标 Word）、PhotoCraft（对标 Photoshop）出自同一技术路线，四个共同点：

  • 纯 Rust 原生实现——不是 Electron 套壳：VectorCraft 27ms 渲染两万图形、WordCraft 61ms 完成 188 页文档首次布局、PhotoCraft 纯 Rust 24 crate 且 unsafe forbid；
  • MIT 开源 · 零订阅——对应商业软件的订阅价格（Illustrator $22.99/月、WPS ¥398/年、Adobe 摄影计划 ¥348/月）为 ¥0；
  • MCP 可指挥——界面能用的操作 AI 也能调用：菜单/工具/命令统一走 JSON 与 MCP 协议，可挂载 Claude Code 分步绘图、批量改稿、无头处理；
  • 全平台 + WASM——macOS / Windows / Linux 原生运行，另有浏览器版本。

VectorCraft：矢量插画

钢笔 / 路径查找器 / 渐变网格的快捷键与 Illustrator 一致，老用户零学习成本；精确布尔运算 + 无限撤销；SVG / PDF / AI 双向导入导出。典型用法：一句话生成矢量图，导出 SVG 再进 Illustrator 改细节。挂载 MCP 只需一条命令：

claude mcp add vectorcraft -- /path/to/vectorcraft-cli mcp

WordCraft：文档处理

文字排版（标题样式、多级编号、自动目录）、表格（合并拆分单元格、跨页重复标题行）、页面控制（分栏、页眉页脚、水印）等普通文档需求基本覆盖；支持 DOCX / ODT / RTF / HTML / Markdown / TXT 读写与 PDF 导出。修订模式可逐条接受或拒绝，带批注与文档比较；389 条 MCP 命令支持批量替换、批量生成报告等场景：

claude mcp add wordcraft -- wordcraft-cli mcp

诚实边界：全部替换未进修订记录、字体/加粗格式记录不全；特殊换行会丢失、PDF 交叉引用异常、图表 / SmartArt / 公式编辑器尚未支持。修订漏一条就可能影响审核——正式合同暂时别用它。

PhotoCraft：位图编辑

菜单布局与快捷键同 Photoshop（67 个工具、真实笔刷引擎支持压感/倾斜/旋转），GPU 合成覆盖 Metal / Vulkan / DX12 / WebGPU，CPU 参考实现与 GPU 互为 oracle 测试（1700+ 测试）。真实 PSD 双向读写：psd-tools 测试集 307/309 文件渲染一致（99.4%）。1500+ 命令单一注册表，UI / CLI / JSON / MCP 调用同一批命令，photocraft-cli mcp 即可接入 AI Agent。发布 12 天收获 4.8 万 GitHub Star（单日最高 +6,244，AI 辅助开发：Claude Opus 5.5，12 天 1000+ 提交）。

诚实边界：early alpha——菜单项 100% 接线到命令，但对 Photoshop 的实际对等度 < 50%；AI 生成式功能、15 个工具与插件生态尚缺失；HEIC 只读、AVIF 仅写、Affinity 只读。适合体验和研究，正式工作流再等等。同类可关注 macOS 独占的 Compositor（Swift、8MB、需 Apple Silicon）。

选型建议：现在该换吗

  • 矢量绘图：想免费开源、想让 AI 帮画 → VectorCraft 可直接平替尝试；
  • 文档处理：体验 AI 批量处理很香，但兼容性（87% 覆盖 vs 62% 完整度）决定敢不敢用——正式文档继续用 Word，等它补齐；
  • 位图修图：工程密度最高、设计起点最对，但 alpha 阶段只建议尝鲜；处理期刊位图的主力仍是成熟软件。

三个项目的共同价值不在「明天就取代 Adobe」，而在验证一件事：图像与文档编辑器可以被开源认真重做一次，并且天然为 AI Agent 预留了操作接口。功能 AI 做得越来越快，细节决定敢不敢用——持续关注、按需引入，是当下最合理的姿势。
