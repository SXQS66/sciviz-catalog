Log₂ Fold Change 到底怎么算

从原始 counts 到 log₂FC：加不加伪计数、要不要标准化、符号怎么解释。

log₂FC差异分析标准化

为什么 Fold Change 需要「对数化」处理？

在转录组等组学分析中，基因表达差异通常以 Fold Change（FC，倍数变化）表示：处理组与对照组的表达量之比。FC = 2 表示上调 2 倍，FC = 0.5 表示下调 2 倍——两者的生物学幅度相同，数值却一高一低。以「无变化 = 1」为中点，上调与下调落在不对称的两侧，直接用原始 FC 做筛选、排序或画图，都会系统性地高估上调信号。

log₂(FC) = log₂(实验组 / 对照组)

对数变换把「以 1 为中心的乘法尺度」改写成「以 0 为中心的加法尺度」：上调 2 倍 → log₂FC = +1，下调 2 倍 → log₂FC = −1，上下调在同一坐标系里完全对称。

FC 原始尺度：不对称的鸿沟

用一个最小例子看清楚问题。A、B 两个基因的生物学变化幅度完全相同（都是 2 倍），但原始 FC 的数值距离相差很远：

基因对照组实验组FClog₂FC生物学幅度
A1002002.0（上调）+1均为 2 倍
B100500.5（下调）−1

在原始 FC 柱状图上，A 的柱子（2.0）是 B（0.5）的 4 倍高——视觉上「上调看起来远比下调剧烈」，而事实并非如此。这就是差异分析必须先做 log₂ 变换的第一个理由：可视化诚实。

统计层面还有第二个理由：原始 FC 的分布严重右偏（下限被 0 截断，且小 FC 密集堆积在 1 附近），不满足 t 检验等参数方法的正态性假设。取 log₂ 后分布近似对称、方差更稳定，后续检验的功效与假阳性控制都更好。在 1000 个模拟基因上的演示（模拟数据，非真实结果）中，取对数使偏度从 +2.3 降到 −0.1、峰度从 8.5 降到 3.0，两项都向正态的 0 / 3 靠拢。

Log₂FC 的三条实操要点

① 阈值是惯例，不是定律

常见做法是把 |log₂FC| > 1（即 2 倍）与 padj < 0.05 一起当筛子用，但这只是领域惯例，不是工具默认值：DESeq2 的 lfcThreshold 默认为 0，limma2 的 topTable() 也不做 LFC 截断，阈值得自己在结果里加。而惯例本身也需要质疑：低表达基因的真实 2 倍变化可能毫无意义，高表达基因 1.5 倍（log₂FC = 0.58）的变化却可能非常关键。结论应结合 FDR 与生物学背景，而非只看 log₂FC。

常见误区：log₂FC 的显著性不能替代 p 值/FDR——火山图上 x 轴（log₂FC）与 y 轴（−log₁₀p）是两个独立维度，同时满足阈值才可称为「显著差异基因」（见 No.022 的讨论）。

② 零计数与伪计数

count 为 0 时 FC 无定义（除以 0），log₂ 也无法计算。Bulk RNA-seq 里标准做法是交给 DESeq21 这类负二项模型：它基于全部样本估计离散度并做 shrinkage（效应量收缩）3，低表达基因的 log₂FC 会被自动压向 0，而不是手工加一个任意伪计数。

③ 报告口径要一致

论文中同时报告 log₂FC（统计与图形）与原始 FC（读者直觉），并注明变换方式与检验工具版本。只报其中一个，审稿人都会追问。

小结

  • 对称性——上下调等幅度差异，log₂FC 绝对值相等；
  • 统计稳健——分布近似正态、方差稳定，检验更可靠；
  • 可视化友好——火山图、热图、MA plot 的对称阈值都建立在 log₂ 尺度上；
  • 学术标准——主流差异分析流程与顶刊图表默认采用 log₂ 尺度。

对数变换是组学差异分析的基石之一：先换尺度，再谈显著。
