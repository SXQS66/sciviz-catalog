🧬 什么是 GO？快速回顾

GO（Gene Ontology）从 3 个维度系统注释基因功能：

BP（生物过程）：如“细胞凋亡”、“免疫应答”

CC（细胞组分）：如“线粒体”、“核糖体”

MF（分子功能）：如“ATP酶活性”、“DNA 结合”

👉 一句话总结：GO 告诉我们基因“在哪儿、做什么、怎么工作”。

✅ 标准分析流程（0 基础友好版）

1️⃣ 读取差异分析结果 → 从 DE_results.csv 开始

2️⃣ 筛选差异基因：|log₂FC| ≥ 1，FDR < 0.05

3️⃣ 基因 ID 转换 → ENTREZID / ENSEMBL（别再直接用 Symbol！）

4️⃣ 设定背景基因 → 一定要用“本次测序检测到的所有基因”

5️⃣ GO 富集分析（超几何检验 + BH 校正）

6️⃣ 结果解读与报告 → 结合你的科学问题，聚焦关键功能条目

🐍 Python 版实战（同样从文件开始）

# pip install gseapy pandas matplotlib

import pandas as pd

import gseapy as gp

import matplotlib.pyplot as plt

import numpy as np

# 1) Load DEG results

df = pd.read_csv("DE_results.csv")

deg = df.query("abs(log2FoldChange) >= 1 and padj < 0.05")["gene_symbol"].dropna().tolist()

bg = df["gene_symbol"].dropna().unique().tolist()

# 2) GO enrichment (Mouse / Human)

enr = gp.enrichr(

gene_list=deg,

gene_sets=["GO_Biological_Process_2023",

"GO_Cellular_Component_2023",

"GO_Molecular_Function_2023"],

background=bg,

organism="Mouse", # change to "Human" for human

outdir="gseapy_out",

cutoff=0.05

)

# 3) Extract BP Top20

bp = enr.results.query("Gene_set=='GO_Biological_Process_2023'") \

.sort_values("Adjusted P-value").head(20)

# 4) Plot bar chart

terms = bp["Term"].str.replace(r"\(\d+\)$", "", regex=True)

plt.figure(figsize=(8,6))

plt.barh(range(len(terms)), -np.log10(bp["Adjusted P-value"]))

plt.yticks(range(len(terms)), terms)

plt.xlabel("-log10(FDR)")

plt.title("GO-BP Enrichment (Top20)")

plt.tight_layout()

plt.savefig("GO_BP_bar.png", dpi=300)

⚠️ 避坑指南：GO 富集常见误区

误区

建议

❌ 直接用 Gene Symbol 富集

✅ 先转 ENTREZID/ENSEMBL，避免匹配错误

❌ 背景基因设为全基因组

✅ 使用本次实验检测到的基因集作为背景

❌ 仅依赖 p-value 判断

✅ 看 FDR (q-value) < 0.05，更稳健

❌ 只做 BP，忽略 CC/MF

✅ 三者结合，功能注释更完整

❌ 罗列全部显著条目

✅ 优先选择与研究最相关的3~5个富集条目，并引用文献

📊 结果怎么看？重点指标解析

GeneRatio：差异基因中落在该通路的基因数量 / 总差异基因数

BgRatio：背景基因中属于该通路的基因数量 / 总背景基因数

pvalue / p.adjust：经过多重检验校正的显著性指标，FDR < 0.05 说明显著富集

🧭 总结：GO 富集的关键点
