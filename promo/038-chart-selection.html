从数据到图形：先看数据形状，再选图型

选错图型，多半是因为先想「画什么好看」，而不是先看「手里是什么数据」。From Data to Viz1的方法是把选择倒过来：先识别数据形状——几个变量？分类还是连续？有没有时间或层次结构？——再让数据形状决定候选图型清单，最后按受众与版面从中挑一张。

数据类型典型图型
Numeric（数值）直方图 · 密度图 · 散点图等
Categoric（类别）条形图 · 饼图 · 箱线图等
Network（网络）网络图 · 和弦图等
Time series（时间序列）折线图 · 面积图等

学习工作流：复制 – 修改 – 出图

data-to-viz 是免费开源的学习平台：交互式决策树推荐图型，每个图型详情页提供可直接运行的 R / Python / D3.js 三语代码，同一张图三种实现对照学习。典型路径（以 R 为例）：

  • 打开 data-to-viz.com → 决策树选择数据形状（例如「两个数值变量」）；
  • 推荐散点图 + 边际分布 → 点进详情页，复制「R code」区块到 RStudio；
  • 缺包就 install.packages("tidyverse")；下载示例数据观察结构 → 把自己的数据转成相同格式替换；
  • Run 出图 → 导出 PDF/PNG 用于论文或报告。

Python 与 D3.js 流程完全一致，切换标签即可。它提供的是优质模板，复杂图表仍需读官方文档微调——但作为入门与提效的加速器足够称职。

plottie：按「图型」找图的导航站

选好图型之后，去哪里找优秀的成品参考？plottie 的信息架构值得所有图库学习：先给分类，不给人一堆图——主页按图型分类，分类页把同类图横向对比，详图页把参数与代码收在一屏内。找图从「翻一百张图」变成「点三次」。
